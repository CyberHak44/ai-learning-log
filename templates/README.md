# Draft templates for discussion

Working drafts that turn the subjects in this repo into documents a client could use. Each one is v0.1 and open to challenge: every template ends with a "Thrashing it out" table showing what was changed and why. Comments and challenges are welcome through GitHub Issues.

All names, figures and vendors are fictional. These are drafts for discussion, not legal advice; a client adapts them to its own policies, contracts and lawyers.
