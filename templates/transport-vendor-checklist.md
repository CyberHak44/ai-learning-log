# Transport vendor checklist (third-party risk)

Draft v0.1 for discussion, 2026-11-04. For reviewing an executive transport supplier. Ask for evidence, not verbal answers. A "Fail" or "Partial" on a high-risk control needs written risk acceptance from [CISO or risk committee] before onboarding.

## 1. Legal and contractual

| ID | Control objective | Evidence required | Status | Notes |
| --- | --- | --- | --- | --- |
| LEGAL-01 | Protect information overheard in transit | Signed services agreement with an NDA addendum covering confidential information heard in vehicles | | |
| LEGAL-02 | No unvetted subcontracting | Clause: drivers are direct employees of the vendor; no subcontracting without written consent | | |
| LEGAL-03 | Liability cover | Insurance certificates for motor and general liability, minimum [AED X] | | |
| LEGAL-04 | Personal data handled lawfully | Data processing agreement in line with the UAE PDPL: what trip and passenger data is held, where, for how long | | |

## 2. People

| ID | Control objective | Evidence required | Status | Notes |
| --- | --- | --- | --- | --- |
| PERS-01 | Reduce insider and reliability risk | Police good-conduct certificates, RTA driving record, employment references | | |
| PERS-02 | Drivers trained in discretion | Training content covering confidentiality, surveillance awareness and defensive driving | | |
| PERS-03 | No recording by drivers | Device policy: company-issued phone for navigation and emergencies; personal phones and smartwatches stored in a locked pouch while carrying executives | | |

## 3. Vehicles and technology

| ID | Control objective | Evidence required | Status | Notes |
| --- | --- | --- | --- | --- |
| TECH-01 | No in-cabin recording | Written confirmation, with photos, that cabin microphones, cabin cameras and voice assistants are disabled on assigned vehicles | | |
| TECH-02 | Privacy from the driver | Physical partition or acoustic glass on tier 1 vehicles | | |
| TECH-03 | No tampering during storage or servicing | Chain-of-custody log and secure overnight parking | | |

## 4. Operations

| ID | Control objective | Evidence required | Status | Notes |
| --- | --- | --- | --- | --- |
| OPS-01 | Protect trip details | Dispatch system with encrypted trip data; no plain SMS with names, flights or addresses | | |
| OPS-02 | Incident handling | Written incident response plan with escalation to [security operations] | | |
| OPS-03 | Backup vehicle | Service level: vetted replacement vehicle within [X] minutes | | |

## Auditor guidance

Do not accept verbal assurances. Ask for a redacted sample of a screening report. Inspect a vehicle, or ask for photos of the disabled microphones.

## Thrashing it out

| # | Draft said | Challenge | Where we landed |
| --- | --- | --- | --- |
| 1 | Drivers must be W-2 employees; DMV and federal checks | US terms, wrong for the UAE | Direct employees; UAE good-conduct certificate and RTA record |
| 2 | Insurance of USD 5 to 10 million | Figure copied from the US market | Client sets the amount in AED |
| 3 | Drivers banned from carrying phones | Unworkable for navigation and emergencies | Company phone only; personal devices in a locked pouch |
| 4 | No data protection control | The vendor holds executive trip data | Added LEGAL-04: data processing agreement under the PDPL |
| 5 | "Ironclad" NDA | Not a legal standard | NDA addendum with clear scope |
